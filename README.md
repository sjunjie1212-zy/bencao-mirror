# 本草镜 BENCAO MIRROR

本草镜是连接人与真实草木的智能感官系统。

当前线上基线：**3.6.4-AF3**。

## 视觉与产品原则

- Digital Herbarium / 数字植物标本馆
- Natural History Archive × Editorial Design × Precision Instrument
- TODAY → IDENTITY → MATERIAL ATLAS → AROMA FIELD → ENCOUNTER → RESULT → 我的本草谱
- Aroma Field 使用已确认的纸上扩散强度；新增本草沿用同一强度，只改变植物自身色相。

## 发布

仓库使用 GitHub Pages。推送到 `main` 后由 `.github/workflows/pages.yml` 自动部署。
