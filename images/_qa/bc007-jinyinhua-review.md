# BC.007 金银花 / Lonicerae Japonicae Flos — 来源级逐图审核

审核日期：2026-09-19
结论：**旧 7 图全部不通过「干燥药材图集」主题验收，已在网站中隔离。**
审核方法：核对 GitHub 正式 manifest、各图对应的原始 Commons 文件说明，并与《中华人民共和国药典》金银花药材部位及外观描述对照。**未直接逐像素查看仓库内的 7 个 WebP；不得把本记录描述为图像像素级或植物学最终鉴定。**

验收锚点：忍冬 *Lonicera japonica* Thunb. 的**干燥花蕾或带初开的花**；花蕾棒状，上粗下细，略弯曲，常呈黄白或绿白色，表面短柔毛。生态图、盛开的鲜花、活体花枝不能直接替代干燥药材或标本摄影。
参考：https://shennongalpha.westlake.edu.cn/en-zh/knowledge/nmm-01af
物种核对：https://mpns.science.kew.org/mpns-portal/drugDetail?drugName=lonicerae+japonicae+flos&filter=&fuzzy=false&nameType=all&query=Lonicerae+Japonicae+Flos

## 后续修正条件

1. 先锁定有可靠基源信息的**干燥忍冬花蕾或初开花药材实物**参考源，保留完整出处和合法使用条件。
2. 每张单独制作、单独查看：Hero、Specimen、Detail 01–05；不是 7 宫格海报、重复局部裁切，不能凭文件数凑满。
3. 每张确认物种、药用部位、干燥状态、形态尺度、画面清晰度；无法判定时标为待核，不能擅自判定通过。
4. 审核合格并实际提交 GitHub 后，逐张更新 manifest、本表与网站映射，最后解除 QC 隔离。
5. 本次拒收不等于断言画面中一定出现其他物种；只表示现有来源无法支持「合格金银花干燥药材图」的结论。
